# cybersecurity-portfolio
These projects were completed as part of the Google Cybersecurity Professional Certificate.
The individual projects will be explained below.

# 1 Security Audit

## Overview

This project involved performing a hypothetical internal security audit. Using a fictional company, Botium Toys, the organisation's security posture was assessed by reviewing its audit scope, identifying risks to critical assets, and evaluating existing security controls.

The audit applies the NIST Cybersecurity Framework (CSF) and includes a controls and compliance checklist covering security best practices, risk management, and regulatory considerations such as PCI DSS and GDPR. The objective was to identify security gaps and recommend improvements to strengthen the organisation's overall security posture.

# 2 Vulnerability Assessment Report

## Overview

The report evaluates the security risks facing a fictional organisation by identifying vulnerabilities, assessing their likelihood and impact, and recommending appropriate security controls.

# 3 Using Linux commands to manage File Permissions

## Overview

This project involved the use of Linux command-line tools to examine, and manage file and directory permissions. With the goal of ensuring users had the appropriate level of access whilst preventing unauthorised access.

To this end, the project involved reviewing existing file permissions, identifying authorisation issues, and modifying permissions using Linux commands to align with security best practices. Further, it required using fundamental Linux administration skills to support system security and access control.
