# Vulnerability Assessment Report

## Overview

This project was completed as part of the Google Cybersecurity Professional Certificate.

The report evaluates the security risks facing a fictional organisation by identifying vulnerabilities, assessing their likelihood and impact, and recommending appropriate security controls.

## Skills Demonstrated

- Vulnerability assessment
- Risk analysis
- Threat identification
- Security documentation
- Risk prioritisation
- Security recommendations
